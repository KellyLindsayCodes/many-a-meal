# 🍽️ Many a Meal

A responsive and interactive web application built using **React** and **Node.js**, integrated with an external API to provide users with an effortless way to search and explore recipes from around the world.

## 🔗 Live Demo

Explore the app here: [Many a Meal - Italian Cuisine](https://kellylindsaycodes.github.io/cuisine/Italian)

## 🌟 Features

- 🔎 **Dynamic Recipe Search:** Search for any recipe using keywords.
- 🏠 **Landing Page:** Clean and modern entry point to the app.
- 🍝 **Cuisine Sections:** Browse recipes by category:
  - Italian
  - American
  - Thai
  - Japanese
- ⚛️ **Built with React:** Fast, component-based frontend experience.
- 🌐 **External API Integration:** Fetches real-time recipe data from a third-party API.

## 🛠️ Technologies Used

- **Frontend:** React, HTML5, CSS3
- **Backend:** Node.js
- **API:** External Recipe API (e.g.Spoonacular)
- **Deployment:** GitHub Pages
